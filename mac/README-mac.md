# Sujood for macOS

Prayer times in the menu bar (macOS 13+). Download `Sujood-mac.zip` from the release, unzip, open `Sujood.app`.
If macOS says the app cannot be opened: right click the app, Open (or System Settings, Privacy and Security, Open Anyway).

Click the menu bar text for the menu. Click the Dock icon for the main card. Settings → General → "Show next prayer in the Dock".

# Sujood для macOS

Время намазов в строке меню (macOS 13 и новее). Скачай `Sujood-mac.zip` из релиза, распакуй и открой `Sujood.app`.
Если macOS пишет, что программу нельзя открыть: правой кнопкой по программе, «Открыть» (или Системные настройки, «Конфиденциальность и безопасность», «Всё равно открыть»).

Клик по тексту в строке меню открывает меню. Клик по иконке в Dock открывает главную карточку. Настройки → Общее → «Показывать ближайший намаз в Dock».
